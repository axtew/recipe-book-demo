# 0003. SPA + PWA на Vite, React и TypeScript

- Статус: принято
- Дата: 2026-08-02

## Контекст и проблема

Нужно приложение, которое ставится на домашний экран телефона, открывается без адресной строки и читает данные офлайн. Оно за логином, поисковикам там делать нечего.

## Рассмотренные варианты

1. **Vite + React 19 + TypeScript (strict), SPA, PWA через `vite-plugin-pwa`.**
2. Next.js — отвергнут как избыточный: приложение app-like, за логином, без SEO.

## Решение

**Vite + React 19 + TypeScript (strict), SPA.** **PWA** через `vite-plugin-pwa` — установка на домашний экран, standalone-режим без адресной строки. Юнит-тесты — **Vitest** (на модуль расчёта КБЖУ и масштабирования).

## Последствия

- SSR нет и не планируется: своего сервера нет, и заводить его ради рендеринга значило бы отказаться от всей архитектуры ([ADR 0010](0010-supabase-without-own-backend.md)); офлайн-чтение на кухне даёт именно PWA.
- Как это устроено на деле (service worker, Cache Storage) — [`architecture.md`](../agents/architecture.md).
