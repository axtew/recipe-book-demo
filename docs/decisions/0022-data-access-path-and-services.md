# 0022. Путь к данным: компонент → хук → сервис → клиент Supabase

- Статус: принято
- Дата: 2026-08-30

## Контекст и проблема

После переноса инструкций из рабочего проекта `Carbon-spa` нужно решить, как слой данных устроен здесь. Это самое вероятное место, где исполнитель срежет угол, поэтому правило вынесено в конвенции отдельным разделом. Названия слоя менялись: `repositories` (2026-08-30), затем возврат к `services` (2026-09-08).

## Рассмотренные варианты

1. **Перенести структуру `src/api`**: один модуль на домен, обычные функции вместо методов класса.
2. Перенести `httpService` из `Carbon-spa` — отвергнуто. Его ценность — дедуплицированный refresh токена при параллельных 401, timeout и abort; всё это `supabase-js` делает внутри себя. Идти через сырой HTTP к PostgREST означало бы потерять типизацию из `database.types.ts`, весь GoTrue (логин, сессия, refresh), Storage для фото и типизированные вложенные выборки. Оборачивать `supabase-js` в `httpService` нечего — он не fetch-образный.
3. Имя `repositories` против `services`:
   - за `repository` — терминологическая точность («граница, отображающая строки хранилища в доменные сущности»);
   - за `service` — практический аргумент: владелец держит в голове два репозитория, и одинаковая раскладка дешевле точного термина.

## Решение

- **Путь зафиксирован жёстко:** компонент → хук TanStack Query → сервис → клиент Supabase. Прямой `supabase.from(...)` вне `src/api/services/` — дефект.
- **`src/api/services/`, а не `repositories/`** (возврат к имени из `Carbon-spa`, 2026-09-08). Содержательное решение не менялось: это обычные экспортируемые функции, а не класс с методами; инжектить в слой нечего, клиент один на приложение.
- **Типы сущностей — плоско в `src/types/`, по файлу на домен** (`products.types.ts`, `recipes.types.ts`, `cookLogs.types.ts`). Папку `data/` из `Carbon-spa` не заводим. Причина: признак деления «api-типы против остальных» нестабилен — форма ответа становится сущностью, сущность попадает в форму, и чтобы не словить циклический импорт, всё стекается в одно место. Домен, к которому относится понятие, — признак стабильный. Домен, переросший один файл, получает папку.
- **Сервис — граница типов:** сгенерированная форма строки не выходит за слой сервисов.
- Правило про `numeric` опровергнуто эмпирически 2026-09-08. Считалось, что PostgREST отдаёт `numeric` строкой и приведение к `number` делает слой данных. Проверка на живых данных (`typeof row.kcal_100`) дала `number`: строкой `numeric` отдают драйверы вроде `node-postgres`, а PostgREST сериализует через `to_json`, и `to_json(numeric)` даёт число без кавычек. Сгенерированный `database.types.ts` был прав с самого начала. Правило заменено на «сверить фактический ответ с типом».
