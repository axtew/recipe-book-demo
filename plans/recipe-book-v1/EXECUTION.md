# Журнал выполнения — recipe-book-v1

Одна запись на фазу. Заполняет исполнитель в конце фазы, до передачи владельцу на ревью.
Нужен, чтобы следующая сессия видела фактическое состояние, а не только план.

Формат записи:

```
## Фаза N — <название>

- **Дата:** YYYY-MM-DD
- **Статус:** выполнена | выполнена с отклонениями | остановлена
- **Модель:** sonnet-5 | opus-5
- **Файлы:** что реально создано и изменено
- **Проверка:** по каждому пункту раздела «Проверка» из плана — результат с фактическим выводом команд
- **Отклонения от плана:** что сделано иначе и почему. Пусто — так и написать
- **Замечено вне фазы:** найденное, но не тронутое (чужие файлы, будущие фазы)
```
