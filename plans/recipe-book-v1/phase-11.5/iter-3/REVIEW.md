## Проверка утверждения разработчика (@mantine/dates 9.7.3)

Утверждение верно. В `Day.mjs:7` `varsResolver` пишет `--day-size` через `getSize(size, "day-size")`, т.е. `var(--day-size-<size>)`. Слои `getStyle` идут в порядке: тема -> `styles` -> `vars` -> `style`, поэтому `--day-size` из `styles` перебивается инлайновым значением из `vars`, а переменные шкалы `--day-size-sm|md` (в `styles.css:218-223` объявлены на том же элементе в классе) перебиваются инлайновым значением из `styles`. Живая проверка разработчика (44x44, 35 ячеек в обоих календарях) согласуется с этим разбором.

Покрытие размеров: `DatePicker` по умолчанию `size: "sm"` (`DatePicker.mjs:17`), `FinishSheet` размер не задаёт; `DatePickerInput` по умолчанию `"sm"`, `CookLogSheet` задаёт `size="md"`. Использований календарей в `src` ровно два, `sm` и `md` покрывают оба, включая явный `size="md"` у `DatePicker` (замечание из Notes итерации 2). `xs`/`lg`/`xl` не используются.
